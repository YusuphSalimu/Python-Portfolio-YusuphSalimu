LeadPulse AI — Multi-Tenant B2B SaaS Platform

An independently architected B2B lead generation and web scraping SaaS platform built with Django and Python. It utilizes Celery and Redis to handle asynchronous background task processing and automated data extraction seamlessly without blocking the core application.

Live Demo

Project Overview

LeadPulse AI was developed to address the challenge of extracting and processing large-scale B2B lead data efficiently without hitting performance bottlenecks. Traditional synchronous scraping workflows often cause server timeouts and high latency for users.

To solve this, LeadPulse AI implements an asynchronous task queue architecture powered by Celery and Redis. Scraping requests are offloaded to background workers, allowing users to track job statuses in real time while maintaining a fast, responsive user interface. The system features secure multi-tenancy, isolating client datasets, and integrates Supabase for persistent, scalable database management and authentication.
